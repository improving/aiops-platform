# charts

[![Artifact Hub](https://img.shields.io/endpoint?url=https://artifacthub.io/badge/repository/infracloud-charts)](https://artifacthub.io/packages/search?repo=infracloud-charts)

The Helm charts the AIOps Platform installs, and the ones it publishes.

Each chart is self-contained and can be installed on its own.
`aiops-platform` installs the control plane; the engine, vector database and notebook charts
are the ones its controllers install for every instance.
Charts are published to <https://infracloudio.github.io/charts>.
